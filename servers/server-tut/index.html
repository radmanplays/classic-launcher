How to make a server

Download the server software for the version you want from omniarchive or betacraft.
Then Download the proxy from here
Then Extract the server software and proxy into the same folder
Make sure to install Node.js
You need to first run the server THEN run this proxy using 
node ws-tcp-bridge --websocket 8080 --minecraft localhost:25565
to allow browsers to join message @radmanplays on discord to get your server added to the serverlist
